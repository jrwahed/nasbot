# نسبوط

نادي خروجات في القاهرة. مفيش عضوية.

موقع كامل بـ **Next.js 15 (App Router) + TypeScript + Tailwind**، عربي بالكامل و`dir="rtl"`،
بوضعين (نهاري/ليلي)، و**21 شاشة** شغالة على الموبايل والتابلت والكمبيوتر.

---

## 1. ازاي تشغّله

```bash
npm install
npm run dev
```

وبعدين افتح <http://localhost:3000>.

### باقي الأوامر

| الأمر | بيعمل إيه |
|---|---|
| `npm run dev` | سيرفر التطوير |
| `npm run build` | بناء الإنتاج |
| `npm start` | تشغيل نسخة الإنتاج |
| `npm run lint` | فحص الكود |
| `npm test` | اختبارات Playwright (بيشغّل السيرفر لوحده) |
| `npm run shots` | لقطات لكل المسارات على 390 و768 و1440 في `shots/` |
| `npm run ref-shots` | لقطات مرجعية للأربع شاشات اللي في ملف التصميم |

> **مهم:** ما تشغّلش `npm run build` والسيرفر شغال — الاتنين بيستخدموا مجلد `.next`.
> لو محتاج، شغّل البناء في مجلد تاني:
> ```bash
> NEXT_DIST_DIR=.next-build npx next build
> ```

### أول تشغيل للاختبارات

```bash
npx playwright install chromium
```

## 2. المرجع البصري

مجلد `design/` فيه ملف التصميم الأصلي وفيه **أربع شاشات** (الرئيسية الليلي · صفحة السبوطة ·
إنشاء الحساب · كشف المجموعة). دي المرجع الأعلى للتصميم.

- `DESIGN_TOKENS.md` — كل الألوان والأحجام والمسافات والزوايا بقيمها الرقمية، ومكتوب جنب كل
  واحدة مصدرها (ملف التصميم ولا البرومبت).
- `COPY.md` — كل النصوص العربية حرفيًا.
- `PLAN.md` — بنية المشروع والمسارات والتعارضات اللي اتحلّت وازاي.

نسخة من ملف التصميم موجودة في `public/design-ref/` علشان `npm run ref-shots` يقدر يصوّرها
ويحطها في `shots/ref/` للمقارنة. **امسح المجلد ده قبل النشر** — هو للتطوير بس.

## 4. القاعدة اتوصّلت — إزاي اتعملت

**كل الواجهات بتنادي `src/lib/api.ts` وبس.** مفيش صفحة واحدة بتعرف مصدر البيانات،
عشان كده التوصيل ما احتاجش أي تعديل في الواجهات — **ما عدا صفحة الدفع**، ودي
اتغيّرت لسبب قانوني مذكور تحت.

### الطبقات

```
src/app, src/components   ← الواجهات (ما بتعرفش القاعدة)
        ↓
src/lib/api.ts            ← الموجّه: قاعدة حقيقية ولا بيانات وهمية
        ↓
src/lib/map-db.ts         ← الترجمة: إنجليزي القاعدة ↔ عربي الواجهة، وقروش ↔ جنيه
        ↓
Supabase (Postgres + RLS) ← الحقيقة الوحيدة
```

العمليات الحساسة **مش** بتعدي من المتصفح:

| المسار | بيعمل إيه |
|---|---|
| `/api/otp/send` · `/api/otp/verify` | الرمز على واتساب، وفتح الجلسة |
| `/api/pay/create` | نية الدفع — بيتحقق من توكن المستخدم مش من أي id جاي من العميل |
| `/api/pay/webhook` | **هو الوحيد اللي بيخلي الحجز `paid`** — بتوقيع HMAC ومقاوم للتكرار |
| `/api/pay/instapay` | تسجيل إيصال التحويل للمراجعة |

`src/lib/server/*` عليها `import 'server-only'` — لو ملف واجهة استوردها بالغلط،
**البناء نفسه بيقع**. يعني مفتاح الخدمة مستحيل يوصل للمتصفح.

### الدفع — يدوي بس

مفيش بوابة دلوقتي (المشروع لسه مش تجاري). العضو بيحوّل على **فودافون كاش**
أو **إنستا باي**، بيرفع صورة التحويل، والإدارة بتأكد من `/admin`.

```
اختار الطريقة → /api/pay/create   → حجز مبدئي + الرقم بيظهر (مهلة ساعة)
حوّل وارفع الصورة → /api/pay/transfer → pending_review (مهلة 24 ساعة)
الإدارة تأكد     → fn_approve_transfer → paid + رسالة واتساب
```

**الحجز ما بيبقاش `paid` من المتصفح أبدًا** — `fn_approve_transfer` للإدارة بس.

الفايدة الجانبية: **إحنا بره نطاق PCI-DSS تمامًا** — مفيش رقم بطاقة بيعدي
علينا ولا بيتخزن عندنا. وفي اختبار Playwright بيفشل لو أي حد ضاف حقل بطاقة.

أرقام التحويل في جدول `settings` مش في الكود:

```sql
update settings set vodafone_number = '010 xxxx xxxx',
                    instapay_handle = 'name@instapay';
```

### الأمان

- **RLS مفعّل على كل جدول.** الافتراضي: مفيش سياسة = مفيش وصول.
- `pair_affinity` (مين اختار مين) **محدش بيقراه** — الوصول الوحيد عبر
  `fn_is_mutual()`، وبترجّع `true/false` بس.
- العنوان الكامل مش موجود في العرض العام أصلًا — مصدره `fn_sbota_address()`
  وبتتحقق إن اللي بيسأل حاجز ودافع.
- «مين حاجز» بترجّع **أرقام بس** من غير أي اسم أو معرّف.
- الصور الشخصية: صاحبها · الكابتن بعد الكشف · اللي حصل بينك وبينهم اختيار متبادل.

للتحقق في أي وقت:

```sql
select * from test_rls();
```

وفي 8 اختبارات Playwright بتضرب على القاعدة الحقيقية في `tests/db.spec.ts`.

### التحليلات

`track()` بتطبع في الـ console، و`logEvent()` بتكتب في جدول `events`
(بدون IP ولا user-agent). الأحداث: `view_schedule` · `open_card` ·
`click_ana_gai` · `start_game` · `finish_game` · `reach_payment` · `paid` ·
`share_type_card` · `use_referral`.

## 5. قواعد المنتج المتبنية في الكود

| القاعدة | فين اتنفذت |
|---|---|
| مفيش تسجيل قبل «أنا جاي» | `SbotaCard` · `/s/[slug]` — الضغط بيوجّه لـ `/join?next=…` |
| الصور الشخصية مخفية قبل الكشف | `fn_group_members` ما بترجّعش `avatar_path` خالص |
| الصور بتظهر للكابتن بس | `/captain/[sbotaId]` هي الشاشة الوحيدة اللي بتعرضها قبل الكشف |
| «رايحين معاك» بعد الاختيار المتبادل | `getMetBefore` — والصور بتبان هناك بس |
| الشات بيتقفل بعد السبوطة بيومين | `chatClosesAt` — والغرفة بتبقى قراءة فقط وعلامة الاستفهام بتنام |
| مفيش شات خاص إلا بالاختيار المتبادل | `fn_open_one_on_one` بترفض من غير `mutual_at` |
| الغامضة محتاجة سبوطتين | `getCompletedCount() < 2` ← الزر معطّل + «روح سبوطتين الأول» |
| كود الإحالة خصم 15% · ومكافأة المُحيل بعد الحضور | `settings` + `fn_referral_reward` |
| الدفع يدوي والإدارة بتأكد | `fn_approve_transfer` — مفيش `paid` من المتصفح |

## 6. الوضعان

`data-theme="day" | "night"` على `<html>`، بيتظبط بسكريبت في `<head>` **قبل أول رسم** علشان
مفيش وميض. الافتراضي من ساعة الجهاز (5 صباحًا ← 5 مساءً نهاري)، وزر في الرأس بيبدّل ويحفظ.

الوضع النهاري بيعرض سبوطات الشغل والصباحيات الأول (`dayOrder` في `src/data/sbotat.ts`)،
وعلامة الاستفهام الحية بتلبس نضارة.

## 7. الصور

كل الصور دلوقتي **مربعات رملي** مكتوب في نصها وصف الصورة الحقيقية المطلوبة بين قوسين مربعين،
عبر `<PhotoPlaceholder label="[…]" />`. **مفيش أي صورة مخزون في المشروع.**

لما الصور الحقيقية تيجي، غيّر `PhotoPlaceholder` لـ `next/image` وسيب باقي الكود زي ما هو.
